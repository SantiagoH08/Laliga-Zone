# LaLiga Zone

Educational football squad builder for LaLiga, using real player data from FBref and Transfermarkt. Not affiliated with LaLiga.

## Features
- Build and visualize football lineups for LaLiga teams
- Search players by name or team
- Real player stats and positions
- Interactive field and UI

## Data Sources
- [FBref](https://fbref.com/)
- [Transfermarkt](https://transfermarkt.com/)

## How to Run
1. Install dependencies:
  ```bash
  npm install
  ```
2. Start development server:
  ```bash
  npm run dev
  ```
3. Build for production:
  ```bash
  npm run build
  ```
